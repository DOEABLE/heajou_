📘 사용설명서

재무기획실 산하 경영혁신 Think Tank — 처음 사용하시는 분도 쉽게 따라할 수 있습니다.

이 탭은 무엇인가요?

사내 규정, 경조사 청구, 복리후생, 업무 절차 등 슈어에 관한 모든 것을 AI가 즉시 답변해 드립니다.
담당자에게 직접 물어보거나 두꺼운 문서를 뒤질 필요 없이, 궁금한 내용을 자연어로 입력하면 바로 답을 확인할 수 있습니다.

사용 방법

  1. 화면 중앙의 입력창에 궁금한 내용을 자유롭게 입력하세요.
    예) "경조사 청구는 어떻게 하나요?", "연차 사용 기준 알려줘"
  2. 🔍 검색 버튼을 클릭하거나 Ctrl + Enter를 누르세요.
  3. AI가 관련 규정을 찾아 답변을 생성해 드립니다.
  4. 이전에 검색한 내용은 화면 아래 📜 이전 대화 기록에서 다시 확인할 수 있습니다.
💡 Tip: 질문이 구체적일수록 더 정확한 답변을 받을 수 있습니다.
예) "경조사 청구" 보다 "부모님 회갑 경조사 청구 금액과 절차 알려줘"가 더 좋습니다.

이 탭은 무엇인가요?

법인카드 승인내역과 지출결의서를 자동으로 대조하여 금액 불일치, 한도 초과, 이상 항목을 색상으로 표시해 드립니다.
수백 건의 데이터도 수 초 만에 처리되어 수작업으로 대조하던 시간을 크게 줄일 수 있습니다.

파일첨부는 버튼 클릭뿐 아니라 드래그 & 드롭으로도 간편하게 첨부할 수 있어, 파일을 끌어다 놓으면 바로 업로드됩니다.

사용 방법

  1. 왼쪽 패널에 법인카드 승인내역 파일을 업로드하세요. (xlsx / xls / csv 형식 지원)
  2. 오른쪽 패널에 지출결의 파일을 업로드하세요. (HTML 또는 CSV 형식 지원)
  3. 🔄 매칭 실행 버튼을 클릭하세요.
  4. 결과 표에서 색상 하이라이트로 이상 항목을 확인하세요.
  5. 필요하면 📥 결과 다운로드 버튼으로 CSV 파일을 저장하세요.
⚠️ 주의: 승인내역 파일을 먼저 업로드한 뒤, 지출결의 파일을 업로드해야 매칭 버튼이 정상 작동합니다.

색상 의미

색상의미확인할 내용
회색 승인번호 매칭 완료 승인내역과 지출결의가 정상 연결된 항목
노란색 금액 불일치 승인금액과 지출결의 합계가 다름 → 금액 재확인 필요
빨간색 한도 초과 지출 금액이 항목별 한도를 초과함 → 사유 확인 필요
파란색 개인 사용 의심 적요에 "개인" 키워드 포함 → 개인 사용 여부 확인 필요

업무추진비 자동 검증

매칭 실행 후 업무추진비 사용 내역을 팀원 수 기준으로 자동 검증합니다.

결과 메시지의미
✅ 업무추진비 체크 완료, 사용 금액이 제한 금액 이내정상 — 한도 내 사용
❌ 업무추진비 정합성 오류, 제한 금액 초과팀원 수 × 20,000원 초과 — 확인 필요
⚠️ 보직자 이상만 올릴 수 있는 내역이 포함팀장·보직자 전용 항목이 일반 직원 명의로 제출됨
💡 참고: 업무추진비 검증은 조직도에 팀장으로 등록된 경우에만 작동합니다.

이 탭은 무엇인가요?

시스템을 사용하면서 불편한 점, 오류, 개선 요청사항을 개발팀에 직접 전달할 수 있습니다.
제출하신 피드백은 개발자에게 즉시 전달되며, 처리 상태를 통해 진행 상황을 확인할 수 있습니다.

사용 방법

  1. 부서를 입력하세요. (필수)
  2. 사용 기능을 선택하세요. — 경영지원연구소 / 법인카드 매칭 / 기타
  3. 문제 유형을 선택하세요. — 오류 발생 / 사용 불편 / 속도 느림 / 기능 요청 / 문의
  4. 의견 및 문제 설명을 구체적으로 입력하세요. (필수)
    예) "법인카드 매칭 실행 후 화면이 멈춥니다.", "업무추진비 한도 기준을 변경 요청합니다."
  5. 📨 제출 버튼을 클릭하세요.
💡 Tip: 문제 설명이 구체적일수록 빠른 처리가 가능합니다.
언제, 어떤 파일로, 어떤 동작을 했을 때 문제가 발생했는지 적어주시면 좋습니다.
