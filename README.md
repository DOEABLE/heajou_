## 📦 시작하기

### 1. 환경 설정

```bash
# 의존성 설치
pip install -r requirements.txt

# .env 파일 생성 (.env.example 참고)
cp .env.example .env
# .env 파일 열어서 값 입력
```

`.env` 파일에 아래 항목을 입력하세요:

| 항목 | 설명 |
|------|------|
| `ADMIN_PASSWORD` | 관리자 탭 접근 비밀번호 |
| `GOOGLE_SHEET_ID` | 피드백 저장용 Google Sheets ID |
| `GOOGLE_CREDENTIALS_PATH` | Google 서비스 계정 JSON 키 파일명 |

> Google 서비스 계정 JSON 키 파일은 프로젝트 루트에 위치시켜야 합니다.

### 2. 서버 실행

```bash
streamlit run services/rag_streamlit.py
```

브라우저에서 `http://localhost:8501` 접속

## 🗂 탭별 기능 안내

### 🐦 경영지원연구소

사내 규정, 경조사 청구, 복리후생 등 **슈어에 관한 모든 것**을 AI가 즉시 답변합니다.

**장점**
- 담당자에게 직접 물어볼 필요 없이 언제든 즉시 검색
- 과거 질문/답변 기록이 자동으로 누적되어 재확인 가능
- `Ctrl+Enter`로 빠른 검색 지원

**사용법**
1. 검색창에 궁금한 내용 입력 (예: `경조사 청구에 대해 알려줘`)
2. 🔍 검색 버튼 클릭 또는 `Ctrl+Enter`
3. AI 답변 확인 및 이전 대화 기록 조회

### 💳 법인카드 매칭

법인카드 승인내역과 지출결의서를 자동으로 대조하여 **오류·한도초과·이상 항목을 즉시 탐지**합니다.

**장점**
- 수백 건의 데이터를 수초 만에 자동 매칭 — 수작업 대조 불필요
- 한도 초과(빨간색), 금액 불일치(노란색), 개인 사용 의심(파란색)을 색상으로 직관적 표시
- 업무추진비 정합성 자동 검증 (팀원 수 기반 한도 계산)
- 보직자 전용 항목 포함 여부 자동 경고
- 결과를 CSV로 즉시 다운로드 가능

**사용법**
1. 좌측: 법인카드 승인내역 파일 업로드 (xlsx/xls/csv)
2. 우측: 지출결의 파일 업로드 (HTML 또는 CSV)
3. 🔄 매칭 실행 버튼 클릭
4. 색상 하이라이트로 이상 항목 확인
5. 📥 결과 다운로드

| 색상 | 의미 |
|------|------|
| 🔴 빨간색 | 한도금액 초과 |
| 🟡 노란색 | 승인금액 ↔ 지출결의 금액 불일치 |
| 🔵 파란색 | 개인 사용 의심 항목 |

### 📝 피드백

서비스 이용 중 불편한 점이나 개선 요청사항을 **개발팀에 직접 전달**할 수 있습니다.

**장점**
- 별도 메신저나 이메일 없이 앱 내에서 바로 피드백 제출
- 제출 즉시 개발자의 Google Sheets에 자동 저장
- 처리 상태(New → Reviewing → In Progress → Resolved → Closed)로 진행 상황 추적 가능

**사용법**
1. 부서명 입력
2. 사용 기능 및 문제 유형 선택
3. 의견 및 문제 상황 상세 입력
4. 📨 제출
